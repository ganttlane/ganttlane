`<Gantt>` is a `div` that the vanilla renderer draws into, with the options as props; `useGantt` is
the same without the `div`. Every [example](../../examples/) has a `react.tsx` next to its
`vanilla.ts`: the [custom tooltip](../../examples/custom-tooltip/) is a React component, and the
[edit session](../../examples/edit-session/) uses `useGantt` and `useGanttState`.
