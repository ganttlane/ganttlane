Every event has an `on<Event>` option and a listener added with `gantt.on(name, handler)`, which
returns a function that removes it. `onBeforeTaskChange` and `onBeforeLinkCreate` run before a
change is committed and can cancel or rewrite it. The [basic chart](../../examples/basic/) logs two
events, and [the working calendar](../../examples/working-calendar-hourly/) uses a before-hook.
