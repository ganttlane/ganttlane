The reference lists every public export of the three packages: functions, interfaces, type aliases
and constants, with their parameters, return types, defaults and examples. It is generated from the
TSDoc comments of the source by [TypeDoc](https://typedoc.org) each time the site is built, so it
always describes the code the site was built from. Members marked `@internal` are not part of it.

The [guides](../guides/concepts/) explain how the pieces fit together; this section is where to
look up a name, a signature or a field.

## Packages

The reference is grouped by package. Each package has one page per entry point of its `exports`,
which lists everything that entry exports, and one page per export.

## How to read a page

- **Pages are by kind.** In a package's sidebar group the pages are listed under Functions,
  Interfaces, Type Aliases and Variables. A type that is an object shape, such as an options or a
  payload type, is an interface or a type alias; a React component is a variable.
- **Type parameters.** `TData` is the type of `task.data`. It flows from the options to every
  handler and result, so a chart made with `createGantt<MyData>(...)` hands you `MyData` back.
- **Defaults** are in the description of a field (for example "Default `'today'`"); the
  [Options guide](../guides/options/) has them in tables, by group.
- **Defined in** at the top of a page links to the source file on GitHub.
